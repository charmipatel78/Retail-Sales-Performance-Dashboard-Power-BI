# 📊Retail Sales Performance Dashboard (Power BI)

## 📌 Overview

This project presents an interactive **Sales Analysis Dashboard** built using Power BI. It provides insights into revenue, profit, customer behavior, and product performance to support data-driven decision-making.

---

## 🚀 Key Features

* 📈 Revenue and Profit Analysis
* 🛒 Order Trends and Sales Performance
* 👥 Customer Insights
* 📦 Product Performance Analysis
* 📅 Time-based Trends (Monthly/Yearly)
* 🎯 Interactive Filters and Visualizations
